2. Основные принципы и локальные данные

2.1. Игра не требует регистрации и не запрашивает у Пользователя имя, номер телефона, адрес электронной почты, почтовый адрес или иные прямые контактные данные.

2.2. Весь игровой прогресс (уровень персонажей, количество игровой валюты, настройки игры, достижения) сохраняется локально на устройстве Пользователя. Оператор не имеет удалённого доступа к этим данным и не передаёт их на свои серверы, так как собственные серверы не используются.

3. Обработка данных сторонними сервисами

Для обеспечения работы Игры и показа рекламы используются сторонние SDK и сервисы, которые могут обрабатывать техническую информацию. Оператор не использует эти данные для самостоятельной идентификации личности Пользователя.

3.1. Yandex Mobile Ads SDK (Рекламная сеть Яндекса)

  • Назначение: Показ рекламных материалов (включая видео за вознаграждение и межстраничную рекламу), измерение эффективности рекламы, предотвращение недобросовестной активности.
  • Какие данные могут обрабатываться: Рекламный идентификатор устройства (Android Advertising ID, если он доступен и разрешён настройками ОС), модель устройства, версия операционной системы, язык и региональные настройки, тип сети, IP-адрес, сведения о версии приложения, события показов и кликов по рекламе, диагностические события.
  • Обработка данных осуществляется в соответствии с Политикой конфиденциальности Яндекса.

3.2. Сервисы RuStore

  • Назначение: Распространение Игры, а также проверка доступности обновлений и запуск обновления по выбору Пользователя.
  • Какие данные могут обрабатываться: Технические сведения о приложении, его версии, устройстве, состоянии RuStore и доступности обновления.

3.3. Оператор не использует Firebase, сторонние аналитические системы (кроме указанных в п. 3.1–3.2) и не передаёт данные третьим лицам в иных целях.

4. Разрешения, запрашиваемые Игрой

Для корректной работы Игра может запрашивать следующие разрешения операционной системы Android:

  • Доступ к интернету и состоянию сети — для загрузки рекламных материалов и обеспечения работы рекламного SDK.
  • Доступ к рекламному идентификатору (если доступен) — для показа персонализированной рекламы и предотвращения мошенничества.
  • Вибрация — для игрового отклика (если используется).

  • Удаление локальных данных: Удаление Игры с устройства автоматически удаляет весь локально сохранённый игровой прогресс.
